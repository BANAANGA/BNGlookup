ADMINISTRATION

Settings & users

Choose which features are public, available to logged-in users, or restricted to administrators.

Site identity

Customize the name and icon shown in the browser and application header.

Use an HTTPS URL. Leave the icon fields unchanged to keep the current icon, or select the default icon to reset. The icon host can see each visitor's IP address. PNG, JPEG, GIF, WebP, or ICO; maximum 256 KB. Uploaded icons are stored in the application database.

BIMI logo

Upload your brand logo as an SVG. It is served at /logo.svg, the URL to use in your domain's BIMI record. It does not change the site icon or header logo. Files with scripts, links, embedded content or external references are rejected; the upload is also checked against the BIMI SVG Tiny Portable/Secure rules.

    Most mailbox providers, including Gmail and Apple Mail, only show BIMI logos for domains with DMARC at p=quarantine or p=reject, and many also require a Verified Mark Certificate (add a=https://…/vmc.pem).

    Default DNS resolver

    This encrypted DNS-over-HTTPS resolver is used for lookups unless a query specifies a nameserver. DNS4EU uses its protective service, which filters domains classified as malicious.

    Feature access

    Public features do not require login. User features require any active account. Admin features require the administrator role.

    Trusted reverse proxies

    Enter the IP addresses or CIDR ranges of proxies that connect directly to BNGlookup, one per line. Only these connections can supply client IP headers. Do not add a public or shared subnet unless every host in it is trusted.

    When enabled, official Cloudflare IPv4 and IPv6 ranges are refreshed automatically. Cloudflare Tunnel users must also trust the local cloudflared connector address.

    Public lookup limits

    Visitors who are not logged in may use the public tools this many times per IP address each day (reset at 00:00 UTC). A whole landing page scan counts as one.

    Port scan policy

    Port scans always require an account, even when the feature is marked Public. Private/local targets are enabled for administrators by default and remain unavailable to users until enabled here. Limits apply to unique TCP ports per target. Bulk scans are capped at 256 unique addresses per request, or 65,536 IPv4 addresses when the zmap engine is enabled.

    Nmap authorized networks

    Nmap remains disabled until an administrator adds authorized CIDR ranges or a user signs in. Successful logins add the observed client IP as one exact host (/32 or /128) for 30 days. The observed IP follows the Trusted reverse proxies setting. The combined allowlist is limited to 254 entries; when full, the oldest automatic entry is replaced. Manual CIDRs are never replaced.

    Manual ranges: up to 254 IPv4 /8–/32 or IPv6 /32–/128 entries.

    SSL certificate (ACME)

    Obtain and renew a free certificate for this web interface from Let's Encrypt using the HTTP-01 challenge. Each domain must resolve to this server and public port 80 must reach BNGlookup (for example, publish 80:3000). Once issued, HTTPS is served on the container's HTTPS port (default 8443; publish 443:8443).

    One per line (up to 20). All names are included in a single certificate and each must resolve to this server. The first name is the primary one.

      Download a backup

      One .tar.gz file with the database (users, settings, monitors, history, logs and statistics), the SSL certificate and the landing page background. Keep it somewhere safe: it contains password hashes, two-factor secrets and certificate keys.

      Restore a backup

      Replaces all current data with the backup and restarts BNGlookup; everyone is logged out. The current data is kept in a pre-restore-… folder in the data volume (the last three are kept). With Docker the container restarts by itself (restart: unless-stopped); without a process manager, start BNGlookup again yourself.

      Site files

      Standard files that crawlers, security researchers and password managers look for. Each one is only served while it is published; changes go live when you save. The hosted MTA-STS policy is managed in the email record builder.

      Landing page

      Visitors who are not logged in see a simple landing page at /. One search runs every tool that is set to Public under Access & network, and counts as a single public lookup. A small login button leads to the full interface. Changes show in the preview right away and go live when you save.

      Logged-in users can always switch with the Simple / Full switch at the top right; their choice is remembered in their browser.
